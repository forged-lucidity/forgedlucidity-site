Why keep this open all day

Because you are about to rely on something.

Most tools hand you an answer. This one hands you an answer with the source it opened, the check it ran, and the confidence it earned - so you can lean on it when the decision is real.

Before you cite it

Check the claim.

A statute, a figure, a quotation, a deadline. Eous opens the primary record and grades the claim against it. A pin cite that is off by a page comes back marked, not missed.

Before you decide

Get the graded answer.

Ask the question. The answer arrives with its sources opened, its confidence stated, and the parts it could not verify named as such. "I don't know yet" is a legitimate result.

Before it resolves

Put a forecast on the record.

Forecasts are sealed before the outcome and scored afterward, in public. The track record is the product, and it publishes wins and losses alike.

How the grader earns the word

The grader is graded.

A model saying it read the file is not evidence that it did. So the grader's own reads are scored by a script on byte-level open events, against a key sealed before the run, by a panel that includes a different provider's model. Every round is recorded - the losses first.

  • Aug 26Rounds 0 and 1: every model scored 12/12 on a gold set whose source was pasted under the claim. A pasted source measures reading, not verification.loss
  • Aug 27v2 design: the critic must open the file itself, among decoys, and a script - not a model - decides whether the bytes were read.switch
  • Sep 2-3Round four: liar control 0/12, open-all control 12/12; four Claude members 0 fabricated reads in 48 rows; the local 3B model fabricated three receipts and the script gave it no credit.win
  • Sep 5Fact layer added: for checkable claims a script renders coupled or decoupled from the opened bytes - 3 net-new catches, 0 false alarms on 6 sound controls.win
